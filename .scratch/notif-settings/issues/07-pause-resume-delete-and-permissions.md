# 07: 暂停、恢复、删除与权限生命周期

**What to build:** 用户能够暂停和恢复规则而不丢失配置，能够确认删除规则并同步撤销目标授权，也能看到系统通知使用权受阻并跳转到系统设置页。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 暂停将规则持久化为非 active 的 `paused`，保留筛选、目标授权和原 `ruleId`。
- [ ] 暂停和恢复立即执行，并提供短时撤销。
- [ ] 恢复把同一规则改回 `active`，不重新生成 `ruleId`。
- [ ] 删除前确认一次，并明确说明将撤销该目标授权。
- [ ] 删除规则后通过权限 store 撤销目标授权。
- [ ] 外部目标授权变化导致状态不一致时显示阻塞错误，不静默重新授权。
- [ ] 系统通知使用权只做状态检测；缺失时跳转系统设置页，不调用隐藏授权或撤销 API。
- [ ] 系统通知使用权被撤销后，受影响规则显示受阻，不显示为正常转发。
- [ ] 测试覆盖暂停、恢复、撤销、删除、授权撤销和外部权限变化。
- [ ] 设备验收确认暂停不发送、恢复后可发送、删除后规则与授权同时消失。
