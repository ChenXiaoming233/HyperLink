# 02: 模块骨架与活体握手

**What to build:** 建立可安装、可启动、可验证的端到端模块骨架。用户能从模块入口和 MiLink 设置入口打开独立面板；面板能通过受认证、版本化的窄 RPC 到达 VoiceAssist 适配器，并显示实时能力与兼容状态。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 提供可构建的 LSPosed 模块和独立设置面板，并支持桌面入口与 MiLink 设置入口。
- [ ] 在 VoiceAssist 内加载范围受控的数据适配器，不把业务逻辑放入 MiLink。
- [ ] 实现固定领域 RPC 的认证、包名校验、签名校验和协议版本握手。
- [ ] 实现统一响应 envelope，至少区分成功、认证失败、协议不匹配、能力不足和未知版本。
- [ ] 面板能显示已连接、未激活、目标进程不可达、兼容性未经完整验收和能力不足状态。
- [ ] 相同 APK 的面板进程与已加载 Hook 协议不匹配时立即拒绝调用。
- [ ] 使用 fake 领域服务覆盖面板状态，使用 Provider handler 测试覆盖认证和协议拒绝。
- [ ] 完成设备级 smoke test：两个入口均可打开面板，合法调用可达，非法调用被拒绝。
