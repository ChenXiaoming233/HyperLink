# 09: 设备级端到端验收

**What to build:** 在真实 HyperOS 设备、VoiceAssist 和 MiLink 环境完成最终端到端验收，证明规格中的高风险路径和跨进程恢复行为成立，并修复验收中发现的问题。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 基线版本完成读、建、改、暂停、恢复、删除及目标授权同步。
- [ ] 现有三条规则加载后，数量、`ruleId`、状态、目标、DSL、规则摘要和顺序无损。
- [ ] 编辑按 source+target upsert，不生成重复规则；恢复不改变 `ruleId`。
- [ ] 删除规则同步撤销目标授权；暂停保留授权。
- [ ] 目标离线时仍可保存，UI 明示不可达且无队列或重试。
- [ ] 系统通知使用权缺失或撤销时，只提示并跳转系统设置页。
- [ ] 快照读取或写入失败时禁止继续写。
- [ ] 结构校验失败后可选择回滚或受控重试；回滚无法验证时持久只读。
- [ ] RPC 拒绝错误签名、错误包名和协议版本不匹配，且不泄露敏感数据。
- [ ] VoiceAssist 被杀、Provider 冷启动、面板重启后状态与故障态正确恢复。
- [ ] 未知版本能力探测通过时写入并显示“兼容性未经完整验收”；探测失败时只读或不可用。
- [ ] 未知字段或无法表达 DSL 存在时整份规则文件禁写。
- [ ] 编辑一条规则后，未修改规则的 `ruleId`、状态、筛选和顺序保持不变。
- [ ] 用一条受控测试通知观察日志，确认只产生一次转发尝试。
- [ ] 记录验收设备型号、系统版本、VoiceAssist 与 MiLink 版本、APK SHA-256、测试证据和剩余风险，并追加到本 ticket 的 `## Comments`。
