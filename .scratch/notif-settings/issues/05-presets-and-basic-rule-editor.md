# 05: 预设与基础结构化编辑器

**What to build:** 用户能够从可编辑预设开始，选择多个应用，组合 IM、焦点通知和短信验证码规则分支，并在保存前查看自动生成的规则摘要。现有规则可按 source+target 安全更新。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 提供“IM、焦点通知、短信验证码”等可编辑预设，不把预设保存为固定规则类型。
- [ ] 多个具体预设生成多个 OR 规则分支。
- [ ] 提供支持搜索、多选、图标和名称的应用选择器。
- [ ] 默认展示可启动应用和规则已引用应用，并可切换显示全部已安装应用。
- [ ] 已引用但未安装的应用继续保留并标记；名称无法解析时显示包名。
- [ ] 支持应用集合、焦点通知和验证码的 andGroups → 规则分支 → 条件编辑。
- [ ] 始终由结构化条件生成规则摘要；筛选变化时更新摘要，状态变化时保留摘要。
- [ ] 编辑已有规则时复用安全写入链路并保留 `ruleId`、状态和创建时间。
- [ ] 测试覆盖预设展开、OR 分支、应用保留、摘要生成和 upsert 更新。
- [ ] 设备验收确认编辑后的规则热生效且未修改规则不变。
