# 03: 无损只读规则面板

**What to build:** 用户能够完整查看目标设备、现有规则、目标授权和系统通知使用权状态。此 ticket 不提供写入，重点证明规则可以无损读取，并对离线、受阻和过期状态给出准确说明。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 展示仅支持通知接收的 PC、PAD 和 MAC 目标，以及在线、可达、授权和接收能力状态。
- [ ] 展示规则的顺序、`ruleId`、来源、目标、状态、完整 DSL 和规则摘要。
- [ ] 展示目标授权与系统通知使用权，明确二者相互独立。
- [ ] 规则中已有但当前离线的目标仍正常显示，并提示不会排队或自动重试。
- [ ] 系统通知使用权缺失或撤销时，相关规则显示为受阻。
- [ ] 面板缓存最近一次成功读取结果时明确标记过期，且不提供基于缓存写入的入口。
- [ ] 提供 fake gateway 的无损读取测试，覆盖数量、顺序、`ruleId`、状态、目标和 DSL。
- [ ] 设备验收确认现有规则在只读展示前后没有文件或 store 变化。
