# 08: 失败恢复、兼容状态与调试重试

**What to build:** 所有写入操作具备完整失败恢复体验，未知版本状态准确可见，并提供一个受控但有明确风险提示的调试重试模式。

**Blocked by:** 06, 07

**Status:** ready-for-agent

- [ ] 第一次结构校验失败后展示弹窗，推荐立即回滚，并提供默认受控重试一次。
- [ ] 默认重试前重新读取并验证当前状态；状态不安全时禁止重试。
- [ ] 始终保留第一次写入前的 LKG，不使用失败后的中间状态覆盖。
- [ ] 默认重试再次失败后直接自动回滚，不再询问。
- [ ] 回滚验证成功后恢复原状态并展示失败原因，不自动重放原写入。
- [ ] 回滚无法验证时进入持久只读故障态，跨页面和 VoiceAssist 进程重启保持。
- [ ] 持久故障态只提供重新检测和再次尝试回滚，不提供强制写开关。
- [ ] 未知版本能力探测通过时全部写入操作均显示“兼容性未经完整验收”。
- [ ] 高级区域提供默认关闭的调试开关，并展示高风险警告。
- [ ] 调试模式最多取消重试次数和重试前验证限制，不绕过初始能力探测、认证、未知字段禁写、LKG 和写入后校验。
- [ ] 调试模式允许用户无条件继续发起原写入，但不承诺必然成功；成功、回滚、退出页面或进程重启后自动关闭。
- [ ] 测试覆盖两种重试路径、持久故障态、调试跳过预验证、调试自动关闭和未知版本文案。
